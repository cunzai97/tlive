# v1.5.0

本版本集中升级飞书执行卡片与 Pi 子代理进度展示。

## 主要变化

- 主代理思考、工具和正文按独立语义块展示；连续同类工具折叠成组。
- 默认采用无逐字动画的累计快照，目标刷新间隔 400ms，保留限流退避与最新状态合并。
- 首段思考即时出卡；主卡思考正文共享约 300 estimated Token 预览，完整脱敏思考可通过详情按钮分页、关闭及重开。
- 编辑详情使用实际提交片段的 `-` / `+` 代码块，删除冗余说明，保留路径、真实状态和详情授权。
- Pi `subagent` 的每个子任务维护独立进度卡，支持并行与 chain 槽位隔离；简化后的同名工具显示为 `searchx2`，失败及中断保留计数。
- 子代理父调用结束后封存主卡，后续主代理思考、工具及正文从新主卡继续；等待当前并行调用结算，不重复历史或制造空卡。
- 发布包包含隔离版 Pi 子代理扩展文件 `integrations/pi-subagent/`，不覆盖用户共享扩展目录。

## 使用说明与保留行为

- 需要实时子代理事件的 Pi client 显式配置 `TL_PI_SUBAGENT_EXTENSION_FILE=/安装目录/integrations/pi-subagent/index.ts`；bridge 与 client 都需要包含新增子代理事件的版本。
- 子代理卡仍坚持一任务一张卡，超预算时从最早历史开始降级，不自动续卡；末尾巨型工具结果可能使较早工具都降为名称，此版本保留该策略。
- 主卡正文仍按既有无损续卡规则处理；子卡降级不改变模型上下文或真实工具返回。
- 详情为内存快照，服务重启后旧卡详情不可继续读取。关闭详情可能留下平台撤回提示或关闭占位。
- 400ms 是服务端目标刷新节奏，不是客户端端到端时延保证。

本次发布不合入 main，不切换现有试用进程。
