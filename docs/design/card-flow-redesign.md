## 产品规则

### 三种内容块

1. 思考块：收到真实思考事件才创建；输出中展开，结束折叠，全文保留；中断/失败标记终态。
2. 模型输出块：按事件原顺序完整展示，不用阶段摘要替代，不静默截断。
3. 工具块：每次调用有稳定 ID、完整输入快照、结果与状态；结果回填原调用，重复/乱序不串块。

### 可扩展工具展示

通过名称映射和适配器注册区分类别；探索 `read`、`grab`（原样保留，另支持实际提供方别名），运行 `bash`，编辑 `write`、`replace`。未知工具使用通用兜底。映射与显示不改变执行或模型收到的结果。

- 探索：显示关键输入/命令与状态，成功原始输出不入卡。
- 运行：显示命令、状态、结果摘要；必要日志可折叠。
- 编辑：显示文件条目与状态，按钮按需打开改动详情。
- 所有错误/阻塞摘要始终可见，不能仅藏在折叠内容内。

### 同类工具连续分组

同类连续工具放在一个可折叠工具组。类别变化或两次工具之间的思考/回复完整内容超过 `50 Token` 时拆组，恰好阈值仍可同组。阈值可配置。

按完整间隔内容判断，不按流式网络片段分别判断。短思考/短回复保留为组内子块，顺序不变，并随父组折叠（用户已同意这个取舍）。活跃思考的父组需要展开；结束后恢复默认收起。超过阈值内容是独立块。

真实 tokenizer 可用时注入；不能把字符数叫做真实 Token。缺少 tokenizer 时必须采用明确标记的估算或保守拆组策略，测试覆盖真实计数注入与阈值边界。

### 编辑详情卡

文件条目使用“查看改动/查看新增内容”按钮，不使用文件路径超链接。详情来自本次调用的输入/结果快照，不点击时读取最新文件；不重新执行工具。

独立非流式详情卡展示本次替换前后或新增内容。内容过长按需分页，只加载当前页。提供关闭按钮：优先撤回机器人自己发送的详情消息；撤回受限时缩成“详情已关闭”；失败不能假报成功。主卡与任务不受影响，原按钮可重新打开。

按钮绑定不透明快照 ID；核验授权用户、聊天/话题、来源消息和目标详情消息；不能使用任意路径或任意消息 ID。重复点击不重复刷卡，分页/关闭串行处理。快照过期时明确提示。

## 统一容量保护

所有卡片创建、编辑、CardKit 更新、详情卡、错误和最终收尾，均通过容量出口。

- 官方限制：卡片/富文本 30 KB；卡片 JSON 2.0 最多 200 个组件/元素。
- 默认软预算：24,000 UTF-8 字节；组件数预留余量。计入结构、转义、标题、状态、按钮、折叠内容；卡片与外层载荷分别估算。
- 优先按块边界续卡；单块超限可分段。保持顺序与全文，不能通过截断丢掉内容。
- 表格按行续段、重复表头；代码块各段闭合；超长行/单元格不得丢失或切坏 Unicode。
- 历史卡不因新增内容全局重排；运行项跨卡标明续接，不留下永久运行标识。
- 超限错误降低预算有限重试；非超限错误不能伪装成成功；幂等重试避免重复消息。

## 开发顺序

1. 落档与隔离分支、回退基线。
2. 容量保护出口和无损拆分。
3. 三类块、稳定调用标识、工具注册与连续分组。
4. 快照注册、详情按钮/分页/关闭、授权与生命周期。
5. 旧模式开关、回放测试、完整检查/构建/覆盖率、独立复核，分阶段提交。

## 验收

- 思考展开/折叠、长短内容边界、同类归组、类型切换、未知工具。
- 原序与完整正文；中文/emoji/超长单段/代码/大量表格、组件数量边界。
- 并发同名同输入工具不合并，乱序结果和重试归原调用，中断终态。
- 全部真实发送/编辑入口的载荷受检；模拟平台超限、限频、部分发送失败、重试不重复。
- 查看/新增/替换详情正确绑定快照，分页无漏无重，重复点击复用。
- 未授权、跨话题/跨消息、过期按钮拒绝；撤回失败占位、关闭失败诚实反馈。
- `npm run check`、`npm run build`、`npm run test:coverage`、`git diff --check`；回放实际代码但不发真实飞书消息。
