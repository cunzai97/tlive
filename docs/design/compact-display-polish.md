## 编辑详情

- 保留工具真实状态、文件路径、简短“替换片段／写入”标签、工具实际结果。
- 删除“未提供旧文件全文”“不是完整文件差异”“未提供旧／新片段”等重复说明；缺失或空片段不编造增删行。
- 对实际提交片段逐行加 `-` / `+`，通过 Markdown `diff` 代码块呈现。
- 脱敏后记录可信 UTF-16 源范围；不通过源码里的“文件：”或其他标签猜测边界。
- 分页按源范围交集渲染，各页独立闭合代码围栏；动态围栏长于源码反引号串，防止源码逃逸。
- 生成围栏和元信息后再次检查实际容量，不符合就缩小分页，保留完整源偏移与 Unicode 边界，不自动产生兄弟详情卡。
- 思考详情排版不变；仍使用冻结执行快照及原 owner/chat/thread/source 授权、TTL、稳定 UUID、关闭／重开机制。

## 子代理结束后的主卡续接

- 仅 Feishu：在主 `subagent` 调用开始时保证已有主卡落地，子流仍各自一张卡。
- partial 子代理结果只更新子流，不提前将主卡工具结算或触发主卡分段。
- 按父工具调用终态触发边界，不按每个 child/chain 槽位触发；并行父调用和已有主工具尚未结算时暂缓，结算后统一封存。
- 封存前等待已消费的子卡状态与主卡在途刷新落地；主卡最后一个快照保持完整工具结果／失败状态。
- 保持同一 turn UUID、全轮递增 block ID、累计工具统计；新物理主卡使用 `${turnId}:segment:${index}` 独立 delivery ID，避免发送缓存返回旧卡。
- 分段只清展示缓冲；不删除模型原始事件或上下文。旧卡不复制到新卡，旧卡的重复 start/final 不能污染新段或阻塞下一次委派。
- 只有后续非空思考／工具／正文才创建新主卡；仅元数据、计时器、空 delta、正常终态不发送空卡。新的真实错误仍可显示。
- 展示边界标志不能触发常规“终态 trace＋answer”拆分；整轮最终完成仍保持原有渠道规则。
- 新段的正文增量仍影响渲染刷新信号，不能因累计工具数非零而仅渲染固定 continuation 占位。
- 只有确认旧物理消息 ID 才允许清段；展示发送失败保留原内容并显示警告，不冒充切段成功。
